# WRF Notes & Experiments

WRF model reference: https://www2.mmm.ucar.edu/wrf/OnLineTutorial/index.php

## 1. WRF executables
- real.exe: interpolate met_em to WRF model coordinates; generate initial/boundary files
- wrf.exe: run the forecast/simulation; produce wrfout files

## 2. Typical I/O files

- Inputs (from WPS): met_em.d01*
- Generated by WRF real.exe: wrfinput_d01, wrfbdy_d01
- Generated by WRF wrf.exe: wrfout_d01_YYYY-MM-DD_HH:00:00

## 3. Minimal run steps (after WPS)
```
cd $WRF/run_or_test_em_real
ln -sf /path/to/WPS/met_em* .
./real.exe
./wrf.exe
```

## 5. Troubleshooting Notes (detailed in Reference)
If geo_em looks partially empty/null: double-check geog_data_path, resolution, and domain coverage.
For GRIB decoding issues: confirm GRIB edition (GRIB1/GRIB2); use correct Vtable; check variables by g1print/g2print
For multi-day emissions preprocessing: prefer scripts that batch multiple days instead of one-day-only executables.
