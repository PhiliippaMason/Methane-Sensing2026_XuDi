# methane-sensing-lab

This repository serves as a central collection of methods, tools, and resources for methane detection and quantification based on remote sensing imagery. It provides a unified directory structure and shared utilities supporting 10 related subprojects, each focusing on different aspects of methane observation, monitoring, and analysis from satellite or aerial data. The repository also offers concise descriptions and links to each subproject to facilitate reuse, comparison, and further development.

## Project List
1. RTM Model (TROPOMI)
2. WRF Model Running (TROPOMI)
3. GEOS-CHEM Model Running (TROPOMI)
4. Data download tool
5. MBMP Method (Sentinel-2)
6. MF Method
7. Validation on Vegetated Area (PRISMA & EMIT)
8. S2MethaNet (AI-based methane detection model)
9. MEQNet (AI-based methane quantification model)
10. Multi-satellite Review

## Directory Structure
- `projects/` Subprojects
- `shared-tools/` Shared tool library
- `.github/` configuration and CI template

## Usage
1. Clone this repository
2. Enter the related subprojects in the `projects/` directory
3. Public functions can be written in `shared-tools/`
